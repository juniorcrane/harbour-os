# HarbourOS

Work-in-progress OS for a brand-new console in development. Build with Godot and drop files in /Build (or move files in /Build to the root of the built project).

Done:

1. Discovery of 5 games (Itch.io), fetched as trending for now.
2. Launching games in fullscreen with no downloads (except for index HTML file to fetch server-side host URL).
